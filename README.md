# UCD Sketch3D

เครื่องมือสเก็ต 3 มิติสำหรับงานสถาปัตย์ของ UCD ทำงานเป็น PWA — ติดตั้งลงหน้าจอได้ทั้ง iPad, iPhone, Android, Windows และ Mac และใช้งานออฟไลน์ได้เต็มรูปแบบ

---

## เอาขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub ตั้งชื่อว่า `sketch3d` (ตั้งเป็น **Public** เพื่อให้ Pages ใช้ได้ฟรี)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้เข้าไปที่ root ของ repo — ลากทั้งก้อนลงหน้า **Add file → Upload files** ได้เลย
3. ไปที่ **Settings → Pages**
   - Source: `Deploy from a branch`
   - Branch: `main` / folder: `/ (root)`
   - กด Save
4. รอประมาณ 1–2 นาที จะได้ลิงก์หน้าตาแบบนี้

   ```
   https://<ชื่อบัญชี-github>.github.io/sketch3d/
   ```

ถ้าจะใช้โดเมนของ UCD เอง (เช่น `sketch.ucd.co.th`) ให้เพิ่ม CNAME record ชี้ไปที่ `<ชื่อบัญชี>.github.io` แล้วใส่โดเมนในช่อง Custom domain ของหน้า Pages

### เวลาแก้ไขทีหลัง

แก้ `index.html` แล้วอัปโหลดทับ จากนั้น**ต้องแก้เลข `CACHE` ใน `sw.js` ด้วย** เช่นจาก `ucd-sketch3d-v3.1.0` เป็น `v3.1.1` มิฉะนั้นเครื่องที่เคยเปิดไว้จะยังใช้ของเก่าจากแคช

## ติดตั้งลงเครื่อง

**iPad / iPhone** — เปิดลิงก์ด้วย **Safari** (เท่านั้น Chrome บน iOS ทำไม่ได้) → ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม

**Android** — เปิดด้วย Chrome จะมีแถบ "ติดตั้งแอป" ขึ้นมาเอง หรือเมนูสามจุด → ติดตั้งแอป

**Windows / Mac** — เปิดด้วย Edge หรือ Chrome จะมีปุ่ม **ติดตั้งแอป** อยู่มุมขวาบนของหน้าเว็บ กดแล้วจะได้หน้าต่างแยกของตัวเอง พร้อมไอคอนใน Start menu / Launchpad

เปิดครั้งแรกต้องต่อเน็ตเพื่อโหลดไฟล์เข้าแคช หลังจากนั้นใช้ออฟไลน์ได้ตลอด

## โครงไฟล์

```
index.html                 ตัวแอปทั้งหมด (HTML + CSS + JS ไฟล์เดียว)
manifest.webmanifest       ข้อมูลแอปสำหรับการติดตั้ง
sw.js                      service worker — แคชสำหรับใช้ออฟไลน์
vendor/three.min.js        three.js r128 (เอนจิน 3 มิติ)
vendor/pdf.min.js          pdf.js — ใช้แปลง PDF เป็นภาพอ้างอิง
vendor/pdf.worker.min.js   worker ของ pdf.js
icons/                     ชุดไอคอนแอป
```

ไลบรารีถูกเก็บไว้ในโปรเจกต์ ไม่ได้ดึงจาก CDN เพื่อให้ออฟไลน์ได้จริงและไม่พังเวลา CDN ล่ม

## การใช้งาน

**ท่าทาง** — Apple Pencil วาดได้ทันทีไม่ต้องสลับโหมด นิ้วสงวนไว้หมุน/ซูม · 2 นิ้วหมุนและซูม · 3 นิ้วเลื่อนมุมมอง · เมาส์: ซ้ายใช้เครื่องมือ ขวาหมุน กลางเลื่อน ล้อซูม

**4 เฟส** — ร่าง → ผิว → วัสดุ → แสง

**เส้นตรง** — แตะวางจุดที่ 1 (ไม่ต้องค้าง) → ถ้าต้องการระยะแน่นอนใส่ในช่อง *ล็อกระยะ* → กดค้างที่จุดที่ 2 จะเห็นแกนสีบอกทิศ ลากจนได้แนว แล้วปล่อยมือ เส้นจึงเกิด

**ฟรีแฮนด์** — ลากอิสระ ค้างนิ่งเพื่อดัดช่วงที่วาดให้เป็นเส้นตรง

**สีแกน** — 🔴 X กว้าง · 🟢 Z ลึก · 🔵 Y สูง · 🟣 ต่อแนว/ตั้งฉาก · ⚫ จุดตัดกริด

**ปิดวงได้เพลน** — เมื่อเส้นบรรจบครบวงระบบสร้างผิวให้อัตโนมัติ รองรับรูปเว้าและวงที่ไม่แบนสนิท

**คีย์ลัด** — `1`–`7` เลือกเครื่องมือ · `F` จัดมุมมอง · `Esc` ยกเลิก · `Enter` จบเส้น · `Ctrl+Z` ย้อน

## ข้อควรรู้เวลาแก้โค้ด

- three.js เป็น **r128** แบบ UMD ไม่มี OrbitControls / BufferGeometryUtils มาให้ — แอปเขียน orbit control, การ merge geometry และ zip writer เองหมด อย่าสมมติว่า import เพิ่มได้
- undo เป็น snapshot ของทั้งโมเดล (`snap()` / `restore()`) state ใหม่ที่ต้อง undo ได้ต้องใส่ใน snap ด้วย
- กริดละเอียดถูก clamp ไว้ที่ 260 เส้นต่อแกน และโหนดจุดตัดสร้างรอบ ๆ `cam.target` เท่านั้น อย่าถอด cap ออก
- ฟังก์ชัน `download()` รองรับทั้งไฟล์ในเครื่องและหน้า claude.ai artifact การส่งออกแบบใหม่ให้เรียกผ่านฟังก์ชันนี้
- ภาพอ้างอิงถูกบีบอัดตอนนำเข้าตามงบ 3 ระดับ แล้วฝังเป็น data URL ลงไฟล์ `.json`
